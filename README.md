# Iris Dataset Analysis Project

A comprehensive analysis of the classical Iris dataset with beautiful visualizations using pastel colors and modern data science techniques.

## 📊 Project Overview

This project provides an in-depth analysis of the famous Iris flower dataset, featuring:
- **Species distribution visualization** with both bar plots and pie charts
- **Pastel color scheme** for aesthetically pleasing visualizations
- **Detailed statistical analysis** for each species
- **Feature correlation analysis**

## 🌸 Dataset Information

The Iris dataset contains 150 samples of iris flowers with the following features:
- **Sepal Length** (cm)
- **Sepal Width** (cm) 
- **Petal Length** (cm)
- **Petal Width** (cm)
- **Species**: Setosa, Versicolor, Virginica (50 samples each)

## 🎨 Visualization Features

The project uses a carefully selected pastel color palette:
- **Light Pink** (#FFB3BA) for Setosa
- **Light Green** (#BAFFC9) for Versicolor  
- **Light Blue** (#BAE1FF) for Virginica

All visualizations include:
- White edges with 2px line width for clean appearance
- Large layout (16x8) for detailed views
- Bold titles and labels
- Value annotations with percentages
- Professional styling with grid overlays

## 🚀 Getting Started

### Prerequisites

Make sure you have Python 3.7+ installed on your system.

### Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   cd test_cursor_project
   ```

2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```

4. **Open and run:**
   Open `iris_analysis.ipynb` and run all cells to see the analysis.
